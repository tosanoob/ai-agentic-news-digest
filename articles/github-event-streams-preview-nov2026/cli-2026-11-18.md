## Tổng quan

GitHub CLI phiên bản 2.105.0 bổ sung lệnh chờ sự kiện pull request trực tiếp qua Event Streams. Đây là **material update** của Event Streams preview công bố 17/11, không phải một giao thức hay dịch vụ độc lập mới.

## Điều gì đã thay đổi?

[GitHub Changelog 18/11](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli/) xác nhận `gh event listen` nhận PR URL và loại sự kiện, tạo subscription, mở kết nối và in mỗi event thành một dòng JSON. Mặc định lệnh thoát sau sự kiện đầu tiên; `--count` đợi nhiều event, `--follow` giữ stream, `--timeout` đặt giới hạn chờ, `--jq` và `--template` lọc trường. Các lệnh `gh event subscription create/list/view/delete` quản lý subscription. GitHub cũng cập nhật các gợi ý từ `gh pr create/view`, `gh run view/watch` và `gh api` sang event listening.

## Chi tiết kỹ thuật

Các loại sự kiện được mô tả gồm submitted reviews, PR state/head changes, merge conflicts và completed check suites. So với [Event Streams preview ban đầu](https://github.blog/changelog/2026-11-17-github-event-streams-is-now-in-preview/), điểm mới là CLI entrypoint có thể dùng ngay trong shell scripts và agent harnesses, thay vì tự xây consumer. Mỗi dòng JSON có thể được parse rồi chuyển thành trigger cho workflow.

## Ý nghĩa đối với agent engineering

**Suy luận kỹ thuật:** Một coding agent có thể tạo PR, checkpoint, chờ review/check suite và resume khi có event. Điều này có thể giảm polling và lãng phí tool calls, nhưng không bảo đảm giảm chi phí theo một tỷ lệ cụ thể. Consumer vẫn cần reconnect, kiểm tra trạng thái PR sau gián đoạn, deduplicate event và thực thi side effects idempotently. Nên đặt timeout và cơ chế fallback khi stream bị ngắt.

## Bằng chứng và giới hạn

**Fact:** Lệnh và flags được GitHub công bố. **Vendor claim:** giảm polling. **Independent evaluation:** chưa xác minh benchmark token/rate-limit savings hoặc delivery guarantees. CLI commands và Event Streams vẫn preview, có thể thay đổi; phải được cấp quyền qua waitlist, không mặc nhiên hoạt động trên mọi account.
