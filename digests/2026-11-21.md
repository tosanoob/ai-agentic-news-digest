## Breaking / Runtime security

### 1. GitHub Enterprise Server 3.23 release candidate — offline AI secret detection (20/11/2026)

GHES 3.23 RC hỗ trợ AI detection cho unstructured secrets trên CPU ngay trong appliance, không yêu cầu GPU hoặc kết nối outbound (public preview). GitHub mở rộng malware advisories cho PyPI, Maven, RubyGems, NuGet, Go, Rust, Composer; Dependabot mặc định chờ ba ngày trước version-update PR; OAuth token expiry tám giờ kèm refresh tokens ở preview.

**Ý nghĩa:** Bảo vệ agent toolchains và air-gapped enterprise deployments; đánh đổi giữa freshness và supply-chain risk. **Giới hạn:** RC, chưa GA; không có benchmark độc lập về detection accuracy.

### 2. Security advisory custom repository permissions GA (20/11/2026)

Bốn quyền tùy chỉnh cho view, edit/manage, accept private reports và publish/request CVE, giúp tách nhiệm vụ security response khỏi repository-admin hoặc organization security-manager. Merge từ private fork vẫn cần admin/security manager.

**Ý nghĩa:** Least-privilege cho vulnerability triage agents và security teams; publish CVE nên có human approval. **Giới hạn:** Cần plan hỗ trợ custom repository roles.

[Nguồn GitHub](https://github.blog/changelog/2026-11-20-security-advisory-permissions-are-now-generally-available/) · [Detailed article](../articles/github-security-advisory-custom-role-ga-nov2026/initial.md)

### 3. BACKFILL — Codename MDASH security-agent pilot (17/11/2026)

GitHub/Microsoft báo cáo 9.791 AI candidate findings từ sáu OSS projects (gồm FastMCP và AutoGPT), qua AI triage và human review thành 99 private verified reports. Tính đến 15/11, 55 issues đã được sửa và 14 fixes đã phát hành. Bảy researchers xác minh thủ công; mỗi report có PoC và suggested fix.

**Ý nghĩa:** Security-agent pipeline nên là detect → dedup → verify → privately disclose → fix, không gửi raw AI findings. **Giới hạn:** Vendor-reported six-project pilot; không suy ra scanner precision/recall từ tỷ lệ 99/9791.
