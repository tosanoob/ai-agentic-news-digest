### 1. GitHub Rubicon: Git storage phục vụ hàng nghìn coding agents — 05/11/2026 (BACKFILL)

GitHub công bố kiến trúc **Project Rubicon**, tách immutable Git packs (Azure Blob Storage) khỏi mutable references/pack manifest (Ref-CAS), dùng virtual replicas làm serving cache và compaction workers chạy riêng. Theo **internal testing do GitHub báo cáo**, hệ thống hỗ trợ 5.000 agents đồng thời trên một repository, 7.200 pushes/giây và read latency thấp. Đây là số liệu vendor, chưa phải benchmark độc lập và không chứng minh mức thông lượng đó khả dụng cho mọi repository.

**Technical implication:** Hệ thống multi-agent tạo read amplification từ CI, deployments và các agents fetch context; kiến trúc immutable objects + CAS trên refs giúp giảm coordination bottleneck. Tuy nhiên, agent orchestrators vẫn phải xử lý merge conflicts, worktree isolation, retry và authorization.

**Caveat:** Một số tính năng như partial/global replicas và materialized views vẫn là roadmap. Ngày 05/11 là ngày xuất bản bài kỹ thuật, không phải xác nhận toàn bộ migration hoàn tất.
