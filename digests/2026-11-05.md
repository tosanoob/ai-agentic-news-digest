## Breaking / Coding agents

### 1. Copilot trong Xcode coding assistant (04/11)
GitHub đưa Copilot vào **coding assistant tích hợp sẵn** của Xcode 27.3 beta (public preview), bên cạnh extension Copilot for Xcode vốn là sản phẩm riêng. Yêu cầu macOS Tahoe 26.6 trở lên; hỗ trợ các gói Copilot. **Ý nghĩa:** coding-agent integration dịch chuyển từ extension sang native IDE assistant. **Giới hạn:** chưa có benchmark độc lập về coding success hay mức độ autonomous execution; chỉ là public preview.

Nguồn: https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant/

## Security / GitHub releases

### 2. CodeQL 2.27.4 (04/11)
Bản cập nhật sau 2.27.3 (đã đưa ngày 04/11), không phải giới thiệu lại AI threat model. Java/Kotlin nhận diện thêm sanitizers và guards, Rust giảm false positives; cập nhật CWE metadata; CLI kiểm tra symbolic links khi đóng gói/publish CodeQL pack và chuyển JVM warnings sang stderr để không làm hỏng JSON output. **Ý nghĩa:** ổn định automation và bảo vệ integrity của published query packs. **Giới hạn:** chưa có benchmark định lượng precision/recall; cần kiểm tra custom query metadata.

Nguồn: https://github.blog/changelog/2026-11-04-codeql-2-27-4-improves-accuracy-and-query-metadata/

## Enterprise agent observability

### 3. Copilot BYOK usage API (03/11 — BACKFILL)
Copilot usage API phân biệt local BYOK (CLI/app kết nối trực tiếp key cá nhân hoặc local models) với enterprise custom models (được cấu hình bởi admin, GitHub quan sát server-side). Có thống kê 1 ngày/28 ngày, theo user và aggregate. **Ý nghĩa:** phân bổ chi phí và kiểm toán shadow AI / local models chính xác hơn. **Giới hạn:** local BYOK telemetry có thể thiếu, token counts phụ thuộc provider; không backfill dữ liệu cũ và local BYOK không breakdown theo tên model.

Nguồn: https://github.blog/changelog/2026-11-03-byok-and-enterprise-custom-models-in-the-copilot-usage-api/
