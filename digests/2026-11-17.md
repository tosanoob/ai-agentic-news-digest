## Agent Frameworks / GitHub Releases

### 2. VS Code 1.146: agent Inbox và Compare Models (16/11)
Copilot weekly release giới thiệu **experimental** Inbox để quản lý sessions từ nhiều workspaces, ưu tiên sessions cần chú ý; **experimental** agent tools để so sánh models; chat windows **preview**. Local harness dự kiến bị gỡ vào 02/2027, Copilot harness hiện là mặc định cho sessions mới. Không tính lại các GA Fable/Carbon/GHES đã lưu. **Implication:** human approval queue và model routing cần metrics khách quan, không chỉ kết quả tự đánh giá của agent. Chưa có benchmark độc lập. ### 3. GitHub Copilot retirements có hiệu lực (16/11)
Claude Opus 4.8, Claude Opus 5 và GPT-5.6 Terra đã bị ngừng trong phần lớn trải nghiệm Copilot; alternatives tương ứng Opus 5.5, GPT-6.1 Sol hoặc GPT-6 Luna. Không suy diễn provider APIs bên ngoài Copilot đã tắt.
