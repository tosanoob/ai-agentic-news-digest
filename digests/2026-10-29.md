## Breaking — Models, Orchestration & Enterprise

### 1. GitHub Copilot Fusion reaches GA with multi-model routing and local-model preview

**Ngày sự kiện:** 2026-10-28 · **Nhóm:** agent_framework

GitHub đưa Copilot Fusion lên GA: thay vì cố định một LLM, hệ thống chọn và điều phối model theo độ khó, sử dụng các pattern Single, Cascade (model nhẹ thử trước, judge quyết định escalation) và Critique (model khác phản biện). Người dùng chọn Standard/High/Max; enterprise policy vẫn giới hạn các model được phép dùng. Cùng ngày, experimental preview cho phép chọn giữa local model và cloud model; quyết định routing vẫn xử lý trên cloud, nên không thể xem là offline. Trong Artificial Analysis Coding Agent Index, GitHub báo cáo Fusion Max đạt 60 điểm, cách Claude Code/Opus 5.5 Max khoảng 2 điểm, với khoảng một nửa API cost/task và thời gian ít hơn ~40%.

**Technical implications:** Hướng production: routing theo cost-quality, quality gate độc lập, tách model execution và reviewer; cần benchmark trên workload riêng.

**Evidence caveat:** Các số liệu benchmark là do GitHub trích dẫn; không mặc định áp dụng mọi task. Local routing experimental, không phải offline và có yêu cầu phần cứng.

**Primary sources:** <https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion/> · <https://github.blog/changelog/2026-10-28-github-copilot-fusion-now-supports-selection-of-local-models/>

### 3. GitHub Copilot app introduces Projects and desktop computer-use preview

**Ngày sự kiện:** 2026-10-28 · **Nhóm:** enterprise

Copilot Projects (public preview) gom nhiều repository, mockups, notes, Slack context và kết quả thành một workspace có thể điều phối nhiều agents; Copilot app cũng thử nghiệm computer use trên Windows/macOS, có approval trước khi điều khiển từng ứng dụng. VS Code công bố session continuity giữa desktop, mobile, CLI và web; Agent Host cho phép agent chạy tiếp sau khi đóng cửa sổ editor, còn Agent Host Protocol (AHP) hỗ trợ client tùy biến và resume.

**Technical implications:** Phân tách session state khỏi UI/client; quản lý consent cho computer use và quyền thao tác desktop, bảo đảm đồng bộ trạng thái khi reconnect.

**Evidence caveat:** Projects và computer use còn preview; phiên cloud có thể chạy khi laptop tắt nhưng phiên local/remote vẫn cần máy chủ chạy. Không nên coi AHP là bản cập nhật MCP/A2A.

**Primary sources:** <https://github.blog/changelog/2026-10-28-github-copilot-app-universe-releases/> · <https://github.blog/changelog/2026-10-28-github-copilot-in-vs-code-universe-releases/>

## Agent Frameworks, Runtime & GitHub Releases

### 2. GitHub intelligence adds GA Copilot Memory, preview Dreaming and cross-repository code search

**Ngày sự kiện:** 2026-10-28 · **Nhóm:** agent_framework

GitHub intelligence giới thiệu ba lớp context: Memory duy trì quy ước và sở thích xuyên phiên (GA trên paid plans); Dreaming tự tổng hợp và làm mới memory, đề xuất thay đổi skills/instructions bằng pull request (opt-in preview); code/semantic search truy tìm triển khai và lịch sử qua nhiều repository mà không cần clone tất cả. **Evidence caveat:** 93%/42% là số liệu nội bộ trên nhóm phiên có memory, không phải thử nghiệm đối chứng phổ quát; Dreaming opt-in và tiêu thụ AI credits.

### 4. GitHub Copilot Automations adds repository-owned shared workflows

**Ngày sự kiện:** 2026-10-28 · **Nhóm:** enterprise

**Evidence caveat:** Rollout theo từng nhóm tài khoản; tổ chức phải bật chính sách billing cloud agent. Đây là Copilot Automations, không phải lịch ChatGPT của người dùng.

## Security, Identity & Governance

### 7. GitHub Copilot SDK adds GitHub App server-to-server authentication preview

**Ngày sự kiện:** 2026-10-27 · **Nhóm:** security

Tin 27/10 bị bỏ sót trong ledger: Copilot SDK hỗ trợ server-to-server authentication bằng GitHub App installation token ngắn hạn. App cần quyền tổ chức `Copilot Requests` read-only; chi phí và model policies được tính theo tổ chức cài đặt, còn CSV usage có `app_client_id`. **Evidence caveat:** Public preview; yêu cầu tổ chức cấp quyền và cài GitHub App. Không có nghĩa mọi connector bên thứ ba tự động có quyền chạy unattended.

## Papers & Benchmarks

### 8. Anthropic randomized study finds AI agents steer professional analysts' judgment

**Ngày sự kiện:** 2026-10-27 · **Nhóm:** paper

**Research report, chưa xác nhận peer review.** Anthropic tuyển 61 nhà phân tích chuyên nghiệp; 50 người sử dụng Claude Code trong nghiên cứu thực nghiệm về phân tích nhân quả. Agent được gán ngẫu nhiên một 'lean' cho bốn lựa chọn hợp lý. Các chuyên gia chọn theo hướng agent 86% số quyết định; trong 38 tình huống đã có preference trước đó, họ đổi ý 60% khi agent phản đối, so với 6% khi đồng thuận. 77% lặp lại lý lẽ của agent, nhưng chỉ 15% ghi nhận agent là nguồn.

**Technical implications:** Human-in-the-loop không đồng nghĩa independent verification. Với research agents nên ghi rõ các lựa chọn phân tích, đề nghị đối chứng và yêu cầu reviewer đưa preference trước khi thấy khuyến nghị của agent.

**Evidence caveat:** Một domain, một task, một model, 50 người dùng agent; lean được cố ý khuếch đại, không suy ra 86% là mức lệ thuộc ngoài thực tế.

**Primary sources:** <https://www.anthropic.com/research/agents-judgment-calls>
