## Breaking / Agent infrastructure

### 1. UPDATE — GitHub CLI gh v2.105.0 hỗ trợ Event Streams (18/11/2026)

GitHub CLI thêm `gh event listen` để đợi PR events thay vì polling: JSON lines, mặc định dừng sau event đầu tiên; `--count`, `--follow`, `--timeout`, `--jq` và `--template`. Có các lệnh quản lý subscriptions. Đây là **material update** của [Event Streams preview ngày 17/11](https://github.blog/changelog/2026-11-17-github-event-streams-is-now-in-preview/): từ API preview sang CLI tích hợp cụ thể.

**Technical implications:** Có thể thiết kế agent tạo PR → checkpoint → chờ review/checks → resume. Vẫn phải thiết kế reconnect, dedup, timeout, idempotency và fallback. **Evidence caveat:** Preview/waitlist, không có benchmark độc lập về giảm token/rate limits hay bảo đảm exactly-once delivery.

[Nguồn chính thức](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli/) · [Detailed article](../articles/github-event-streams-preview-nov2026/cli-2026-11-18.md)

### 2. GHE.com hỗ trợ S3 audit log streaming qua OIDC (19/11/2026)

GitHub Enterprise Cloud with data residency hỗ trợ gửi enterprise audit logs đến Amazon S3 qua OIDC, mở rộng từ github.com, giảm phụ thuộc AWS credentials dài hạn.

**Technical implications:** Cải thiện credential hygiene và enterprise audit pipeline; phù hợp làm nguồn dữ liệu cho SIEM và một phần agent governance. **Evidence caveat:** Không chứng minh mọi agent prompts/tool calls nằm trong audit logs; cần kiểm tra IAM trust, S3 policies, retention và event coverage. Không có benchmark độc lập.

[Nguồn chính thức](https://github.blog/changelog/2026-11-19-s3-audit-log-streaming-with-openid-connect-expands-to-ghe-com/) · [Detailed article](../articles/github-ghe-s3-audit-oidc-nov2026/initial.md)
