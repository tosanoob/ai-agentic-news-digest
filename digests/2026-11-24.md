## Breaking / Agent orchestration

### 1. GitHub Issue Statuses và Repository Boards public preview — 23/11/2026

GitHub thêm bảy trạng thái issue: Backlog, Todo, In progress, In review, Done, Not planned, Duplicate. Agent được gán issue sẽ tự chuyển trạng thái sang In progress; PR được liên kết có thể đưa issue sang In progress/In review. GraphQL, REST và GitHub MCP server hỗ trợ đọc/ghi trạng thái; trạng thái có thể làm trigger cho Copilot automations. Repository saved views hỗ trợ board layout và kéo thả.

**Ý nghĩa kỹ thuật:** coding agents có thể chia sẻ tiến độ, kích hoạt orchestration dựa trên workflow states và giảm polling thủ công. Nhưng status không thay thế xác nhận CI/PR thực tế; cần kiểm soát race conditions, idempotency và permissions.

**Evidence caveat:** Public preview, không có benchmark độc lập về task success hoặc tiết kiệm token. Đây là hỗ trợ MCP server, **không phải cập nhật MCP specification**.

**Nguồn chính:** [GitHub Changelog, 23/11](https://github.blog/changelog/2026-11-23-issue-statuses-and-repository-boards-are-in-public-preview/). **[Bài phân tích](../articles/github-issue-statuses-repository-boards-nov2026/initial.md)**.

## GitHub Releases / CI quality

### 2. GitHub Code Quality kiểm tra định dạng coverage upload — 23/11/2026

Action `upload-code-coverage` giờ báo lỗi nếu report không phải Cobertura XML hợp lệ, thay vì báo upload thành công nhưng coverage không xuất hiện trong PR. Các báo cáo Cobertura hợp lệ có sai khác cấu trúc nhỏ được xử lý linh hoạt hơn; dòng thiếu line number/hit count được bỏ qua riêng.

**Ý nghĩa kỹ thuật:** coding agents và CI pipelines nhận phản hồi fail-fast rõ ràng hơn; cần xuất/convert Cobertura XML trước upload. Áp dụng với GitHub Team và Enterprise Cloud (kể cả data residency) khi Code Quality được bật, **không có trên GHES**.

**Evidence caveat:** Đây là cải tiến validation, không phải benchmark hoặc AI scanner release; chưa có số liệu độc lập về chất lượng code.

**Nguồn chính:** [GitHub Changelog, 23/11](https://github.blog/changelog/2026-11-23-code-coverage-uploads-now-flag-invalid-report-formats/). **[Bài phân tích](../articles/github-code-coverage-upload-validation-nov2026/initial.md)**.
