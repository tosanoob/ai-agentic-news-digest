## 🔴 Breaking & runtime security

### 1. Cursor marketplace distributes malicious Claude Code extension builds 2.1.312 and 2.1.313

**Ngày sự kiện gốc:** 2026-10-29 · **Loại:** Security · **Trạng thái:** New event

**Phát hiện:** Cursor xác nhận marketplace đã phân phối các bản `anthropic.claude-code` **2.1.312 và 2.1.313** bị chỉnh sửa độc hại cho Windows/macOS trong khoảng **02:27–13:35 Pacific, 29/10**. Payload cố gắng thêm SSH public key vào `authorized_keys`, mở reverse SSH tunnel, cài cơ chế persistence và gửi thông tin máy chủ. Cursor đã gỡ bản phát hành, rebuild marketplace, rotate keys và phối hợp ngắt máy chủ của kẻ tấn công. Thông báo ngày 30/10 bổ sung IOCs và làm rõ **cả hai phiên bản**, không chỉ 2.1.313.

**Hành động ưu tiên:** Kiểm tra extension versions, tìm key có comment `svc-telemetry`, cách ly máy có dấu hiệu chạy payload; dùng quy trình khắc phục chính thức của Cursor và rotate credentials từ máy sạch. **Gỡ extension đơn thuần chưa chắc xóa persistence.**

**Technical implications:** Extension marketplace là supply chain có khả năng thực thi code ngay khi load, không cần prompt. Agent governance phải gồm extension provenance, auto-update policy, endpoint telemetry và credential isolation.

**Evidence caveat:** Cursor nói việc bật SSH thường thất bại nếu thiếu quyền admin và chưa có bằng chứng official Anthropic distribution bị ảnh hưởng. Chưa biết chính xác số máy thực sự bị kiểm soát; không khẳng định mọi người dùng Cursor bị xâm nhập.

**Nguồn chính thức:** <https://cursor.com/blog/claude-code-extension-security-notice> · <https://forever.security/blog/claude-code-extension-compromised>

### 2. EMBRACE research exposes embedded browser trust boundary flaws in five AI coding tools

**Ngày sự kiện gốc:** 2026-10-29 · **Loại:** Security · **Trạng thái:** New event

**Phát hiện:** Nhóm Forever Security công bố EMBRACE, một **nhóm lỗi thiết kế** trong embedded browsers của năm AI coding tools: Cursor, GitHub Copilot, Codex, VS Code và Claude Desktop. Kết quả thử nghiệm gồm code execution qua agent trong Cursor; spoof URL trong Copilot; đọc file vượt khỏi project trong Codex, VS Code và Claude Desktop.

**Trạng thái lúc công bố:** Theo nhóm nghiên cứu, Cursor đã vá ngày 01/10 và Copilot vá ở build 1.1.29 ngày 13/10; **Codex và VS Code chưa có bản vá** tại thời điểm báo cáo 29/10. Không coi đây là năm CVE có cùng mã hay một zero-day duy nhất.

**Technical implications:** Browser isolation bị suy yếu khi host app cấp quyền đọc local files, gửi message tới agent hoặc để trang tự khai báo URL. Nên cô lập preview khỏi file system/credentials, kiểm tra origin độc lập và không coi một cú click là biện pháp xác thực đủ mạnh.

**Evidence caveat:** Đây là PoC từ nhà nghiên cứu, không phải bằng chứng tấn công hàng loạt; trạng thái bản vá có thể thay đổi sau ngày 29/10. **Sự kiện này khác hoàn toàn** sự cố marketplace extension ở mục 1.

**Nguồn chính thức:** <https://forever.security/blog/embrace-hacking-5-ai-assistants-embedded-browsers> · <https://forever.security/blog/embrace-hacking-5-ai-assistants-embedded-browsers-technical>

### 3. Mistral releases open weights for Large 4 (Le Chonk), advancing coding and defensive cyber evaluations

**Ngày sự kiện gốc:** 2026-10-29 · **Loại:** Model release · **Trạng thái:** New event

**Điều mới:** Mistral Large 4 đã preview ngày **06/10**; mốc **29/10** là **phát hành weights tải về và tự triển khai**, đồng thời có thêm kết quả sau RL. Model MoE multimodal có khoảng **1 nghìn tỷ tham số tổng**, **52 tỷ tham số active** mỗi lượt.

**Benchmark được Mistral báo cáo:** Artificial Analysis Coding Agent Index **48%** (47% ít token hơn model open-weight so sánh); Terminal-Bench 4.0 **41%** (+13 điểm phần trăm so với preview); Artificial Analysis Cyber Index **51%**; tỷ lệ từ chối trên nhóm malicious cyber prompts **96,6%** trong thiết lập nhà cung cấp. Ba mức reasoning: Low, Medium, High.

**Technical implications:** Open weights cho phép on-prem inference, kiểm soát dữ liệu và custom deployment; đặc biệt hữu ích khi công ty không thể đưa source code hoặc security telemetry lên cloud.

**Evidence caveat:** FrontierCode 2.0 là benchmark private; số liệu và safety claims cần kiểm chứng độc lập. Open weights cũng có nghĩa guardrails cập nhật ở hosted API không tự động áp dụng cho bản weights đã tải.

**Nguồn chính thức:** <https://mistral.ai/news/mistral-large-4-oss/> · <https://mistral.ai/news/mistral-large-4/>

### 4. GitLab Orbit context graph reaches GA with MCP access for coding agents

**Ngày sự kiện gốc:** 2026-10-29 · **Loại:** Enterprise · **Trạng thái:** New event

**Điều mới:** GitLab Orbit chính thức **GA ngày 29/10**. Đây là permission-aware context graph liên kết source code, merge requests, CI pipelines, deployments, vulnerabilities và ownership. Các coding agents như Claude Code, Codex, Cursor và OpenCode có thể truy cập qua **MCP** hoặc GitLab CLI; không phải phiên bản MCP specification mới.

**Số liệu:** GitLab báo cáo trên các bài test nội bộ, Orbit giảm **tối đa 45 lần số retries** và **tối đa 4,5 lần số tokens**. Một đối tác thử nghiệm trên **79 merge requests** ghi nhận reviewer dùng graph đạt khoảng **70%** expected inline comments so với khoảng **58%** cho RAG trong thiết lập của họ.

**Technical implications:** Với security/vulnerability agents, graph giúp truy vấn mối liên hệ giữa dependency, deployed services, exposed versions và team ownership; có thể giảm nested tool loops và số lần tải context lặp lại.

**Evidence caveat:** Những số liệu 'up to' là kết quả chọn lọc của nhà cung cấp; so sánh RAG chỉ thuộc một bài thử nghiệm, không kết luận graph luôn hơn mọi RAG. GA bắt đầu từ GitLab.com Premium/Ultimate; self-managed triển khai sau.

**Nguồn chính thức:** <https://about.gitlab.com/blog/gitlab-orbit-ga/>

## 🛠️ Agent frameworks & GitHub releases

### 5. LangGraph Python 1.2.19, SDK 0.4.11 and JS 1.6.0 improve streaming event semantics and reconnection

**Ngày sự kiện gốc:** 2026-10-30 · **Loại:** GitHub release · **Trạng thái:** New event

**Release gốc ngày 30/10 (UTC):** LangGraph Python **1.2.19**, Python SDK **0.4.11** và LangGraphJS **1.6.0**. Python core sửa `trace_policy` làm thay đổi streamed payload, namespace của message/tool events, streaming subgraphs và trạng thái paused tools. SDK tăng độ tin cậy SSE reconnection qua backoff, `Last-Event-ID`/cursor state và xử lý stream chunks. JS 1.6.0 điều chỉnh namespace cho graph/subgraph events.

**Technical implications:** Production agents chạy streaming hoặc resumable sessions cần regression test trên event consumers, namespace filters, retry/reconnect, cancellation và khả năng replay. Đặc biệt quan trọng nếu FE hiển thị tool events theo subgraph.

**Evidence caveat:** Đây là reliability/stream semantics release, không phải benchmark reasoning mới; namespace behavior có thể làm thay đổi assumptions của client. Khác release 1.2.18 ngày 26/10 đã lưu.

**Nguồn chính thức:** <https://github.com/langchain-ai/langgraph/releases/tag/1.2.19> · <https://github.com/langchain-ai/langgraph/releases/tag/sdk%3D%3D0.4.11> · <https://github.com/langchain-ai/langgraphjs/releases/tag/%40langchain/langgraph%401.6.0>

## 📚 Papers & benchmarks

### 7. EnvOS audits dynamic computer-use agent tasks with certified environment changes and independent grading

**Ngày sự kiện gốc:** 2026-10-29 · **Loại:** Research · **Trạng thái:** Paper / benchmark

**Trạng thái:** arXiv **preprint nộp 29/10**, ghi nhận **được nhận vào NeurIPS 2026 Workshops**; workshop acceptance không đồng nghĩa full-conference/journal peer review.

**Nghiên cứu:** EnvOS xây môi trường có thể thay đổi giữa tác vụ, xác nhận update đã xảy ra, task còn giải được và grader có thể tái kiểm tra từ evidence. Trong clinic-booking tasks, Opus 5 đạt **0/16** khi không có cập nhật, **2/16** khi được nhắc kiểm tra lại, và **15/16** khi được hiển thị giá trị mới. Trên 39 corrupted episodes từ bộ ngoài, pipeline phát hiện **25**, so với **4** bằng simple log checks.

**Technical implications:** Đánh giá computer-use agents phải test **stale-state awareness** và chất lượng môi trường/grader, không quy toàn bộ lỗi cho model. Dùng independently verified state transitions và evidence replay.

**Evidence caveat:** Mẫu bài test nhỏ theo domain; con số không đại diện success rate của mọi browser agent.

**Nguồn chính thức:** <https://arxiv.org/abs/2610.40246>

### 8. CodeSpecWeave synthesizes interdependent coding requirements and benchmarks long-horizon agents

**Ngày sự kiện gốc:** 2026-10-29 · **Loại:** Research · **Trạng thái:** Paper / benchmark

**Trạng thái:** arXiv **preprint nộp 29/10**, chưa xác minh peer review.

**Nghiên cứu:** CodeSpecWeave tạo tasks coding có **ràng buộc phụ thuộc lẫn nhau**, không chỉ checklist chức năng. Tác giả tạo **4.670 training tasks** từ **2.865 repositories** và benchmark **100 tasks / 1.044 specifications**. Một synthesis agent sinh yêu cầu và tests; review agent kiểm tra reliability của tests bằng nhiều trajectories trước khi sử dụng cho RL.

**Technical implications:** Coding-agent benchmarks nên chấm cả interface compatibility, error handling, backward compatibility, side effects và các ràng buộc liên quan; pass một unit test chưa đủ để bảo đảm đáp ứng SRS.

**Evidence caveat:** Kết quả RL improvement do tác giả công bố; chưa có independent replication, không gán một tỷ lệ tăng trưởng cụ thể nếu abstract không cung cấp.

**Nguồn chính thức:** <https://arxiv.org/abs/2610.40256>

### 9. Simulated psychiatric intake RL agents evaluated in blinded psychiatrist study

**Ngày sự kiện gốc:** 2026-10-29 · **Loại:** Research · **Trạng thái:** Paper / benchmark

**Trạng thái:** arXiv **preprint nộp 29/10**, chưa xác minh peer review.

**Nghiên cứu:** Multi-turn RL trong môi trường mô phỏng cho text-based psychiatric intake. Nghiên cứu randomized double-blind crossover dùng **120 encounters** (60 matched pairs), **32 psychiatrists** đóng vai standardized patients và **15 independent psychiatrists** chấm transcript. RL agent tốt hơn base model ở **76,7%** matched pairs; under-triage trên bộ adversarial simulation giảm từ **30,5%** xuống **12,9%**.

**Technical implications:** Simulation có thể là nguồn tạo training/evaluation data cho specialized agents, nhưng cần independent expert scoring, adversarial cases và guardrails ngoài model.

**Evidence caveat:** Đây là **tình huống mô phỏng**, không phải bằng chứng agent có thể chẩn đoán/triage bệnh nhân thật an toàn hoặc thay bác sĩ.

**Nguồn chính thức:** <https://arxiv.org/abs/2610.40476>
