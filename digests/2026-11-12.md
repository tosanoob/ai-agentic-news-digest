## Breaking — Runtime security

### 1. Git vá 6 CVE, gồm code execution qua recursive clone — 10/11 (BACKFILL)
Git 2.56.1 và các maintenance patches sửa sáu lỗ hổng ở recursive clone, refs, merge, binary patches và fast-import. Đáng chú ý CVE-2026-111760 có thể khiến clone repository độc hại dẫn đến thực thi code. Với coding agents, clone/merge/apply patch là bề mặt tấn công cấp runtime; phải vá Git trong runner và sandbox, không chỉ thêm prompt safeguards. GitHub đã vá hạ tầng hosted, đang phối hợp cập nhật bundled Git. **Caveat:** các điều kiện khai thác khác nhau; không mặc nhiên ảnh hưởng mọi agent. [Nguồn GitHub](https://github.blog/open-source/git/git-security-vulnerabilities-announced-7/) · [Bài phân tích](../articles/git-six-security-vulnerabilities-nov2026/initial.md).
