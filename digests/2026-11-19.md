### 1. GitHub Copilot bổ sung tám verified MCP connectors (18/11/2026)

Public preview thêm tám GitHub-verified MCP connectors: Box, Buildkite, Calendly, ClickUp, Mixpanel, Supabase, Webflow, Wix; có thể kết nối trên app/CLI/VS Code/web, chịu MCP allowlist và admin policies.

**Technical implications:** Cho phép coding agent kiểm tra schema Supabase trước migration hoặc điều tra Buildkite CI failure ngay trong coding session. Thiết kế production cần phân quyền từng connector, tránh cấp write scope cho read-only tasks, log tool calls và yêu cầu approval với thay đổi dữ liệu.

**Evidence caveat:** Public preview trên mọi Copilot plans; Business/Enterprise cần bật Editor preview features và có thể phải cập nhật MCP allowlist. Một số nhà cung cấp yêu cầu bật MCP ở phía dịch vụ. Đây là mở rộng danh mục connector, KHÔNG phải MCP specification release. Không có benchmark độc lập.

[Nguồn chính thức](https://github.blog/changelog/2026-11-18-connect-supabase-box-calendly-and-more-to-copilot/) · [Detailed article](../articles/github-copilot-verified-mcp-connectors-nov2026/initial.md).

### 2. Gemini 4 Neon GA trong GitHub Copilot (18/11/2026)

GitHub đưa Gemini 4 Neon GA vào Copilot Pro+/Max/Business/Enterprise, rollout dần; Google claim chất lượng gần Carbon với chi phí token thấp hơn, phản hồi nhanh và ít sửa code ngoài yêu cầu hơn; chưa có independent benchmark.

**Technical implications:** Có thể thử Neon như middle tier giữa Flash và frontier models cho coding agents. Đánh giá trên cùng bộ tasks với Carbon/Hydrogen: success rate, unwanted edits, hallucinated tool results, latency và cost per resolved task; cố định harness/effort để so sánh.

**Evidence caveat:** Thông báo là GA trong Copilot, không chứng minh model lần đầu phát hành ngày này. Không có con số benchmark hoặc giá token cụ thể trong nguồn; các tuyên bố chất lượng là vendor claims, không phải independent evaluation. Rollout dần.

[Nguồn chính thức](https://github.blog/changelog/2026-11-18-gemini-4-neon-in-github-copilot/) · [Detailed article](../articles/github-gemini-4-neon-copilot-ga-nov2026/initial.md).

### 3. GitHub Copilot team customizations GA: shared Agent Plugins (18/11/2026)

Team maintainers và org owners có thể đặt approved Agent Plugins làm team defaults trên VS Code, Copilot app và CLI; direct members nhận mặc định, child teams không kế thừa; enterprise/org policies luôn ưu tiên.

**Technical implications:** Đây là tầng phân phối agent skills/tools có quản trị theo team, giảm drift cấu hình giữa developers. Với enterprise, nên version-pin plugin packages, review nguồn marketplace, enforce allowlist, kiểm thử plugin updates và audit quyền tool.

**Evidence caveat:** GA cho Copilot Business/Enterprise, không phải cơ chế ép buộc mọi thành viên; enterprise và org policies luôn thắng team defaults. Không có số liệu về năng suất hoặc an toàn được đánh giá độc lập.

[Nguồn chính thức](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team/) · [Detailed article](../articles/github-copilot-team-plugin-customizations-ga-nov2026/initial.md).

### 4. GitHub Team tự động chạy security risk assessments (18/11/2026)

GitHub Team organizations được tự động chạy security risk assessments miễn phí; org admins/security managers xem exposed credentials, code vulnerabilities và mức rủi ro để ưu tiên xử lý.

**Technical implications:** Có thể dùng kết quả như một tín hiệu đầu vào cho security triage, nhưng cần correlate với deployed software inventory, CVE/KEV và exposure thực tế trước khi ưu tiên remediation. Không thay thế secret rotation, SAST hoặc full vulnerability assessment.

**Evidence caveat:** Thông báo không nêu lịch chạy, mức coverage, detection rates, thời gian giữ findings hoặc khả năng tự động remediation. Không nên khẳng định continuous monitoring với SLA cụ thể hay benchmark precision/recall.

[Nguồn chính thức](https://github.blog/changelog/2026-11-18-security-risk-assessments-run-automatically-on-github-team/) · [Detailed article](../articles/github-team-automatic-security-risk-assessments-nov2026/initial.md).

### 5. BACKFILL: Copilot CLI hỗ trợ Microsoft Entra sign-in và M365 inference (17/11/2026)

Public preview: Copilot CLI 1.0.113+ hỗ trợ Entra SSO cho GitHub EMU qua OIDC hoặc dùng Microsoft 365 Copilot inference/license tùy entitlement; Windows/macOS trước, Linux sau; có thể dùng Work IQ MCP.

**Technical implications:** Quan trọng với enterprise agents vì tách identity provider, inference provider và license governance. Trước khi triển khai, xác nhận entitlement, data boundaries, policy, billing, scope của Work IQ MCP và tránh nhầm SSO thành quyền truy cập dữ liệu.

**Evidence caveat:** Public preview, giới hạn OIDC EMU và Windows/macOS; Linux chưa có. Microsoft 365 inference khác GitHub inference và chịu policies/limits khác nhau. Không có benchmark hiệu năng mới.
