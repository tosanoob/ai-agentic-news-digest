## 🔴 Agent security, frameworks và GitHub releases

### 1. Dependabot hỗ trợ Agent Package Manager (APM)

**Ngày gốc: 03/11/2026.** Dependabot nay có thể tạo PR cập nhật các git dependencies của agent skills, prompts và instructions khai báo trong `apm.yml`, đồng thời tái tạo `apm.lock.yaml`. Cấu hình `package-ecosystem: apm` trong `.github/dependabot.yml`. **Giới hạn:** đây chỉ là version updates, **không phải security updates** hay bằng chứng package an toàn. **Ý nghĩa:** agent skills trở thành supply-chain dependencies cần pin version, review diff và kiểm soát provenance.

**Nguồn chính thức:** https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager/

### 2. GitHub Copilot tích hợp JetBrains Air qua ACP

**Ngày gốc: 03/11/2026.** Agent Client Protocol (ACP) cho phép dùng Copilot làm coding agent trong JetBrains Air, chạy local hoặc cloud; có thể theo dõi các sessions song song. Cloud tasks chạy Docker container trên VM mới, qua proxy và không giữ state giữa tasks. **Giới hạn:** cloud cần Air Teams business org và admin enable; Air analytics không bao gồm usage Copilot và admin Air không đặt được spending limits cho Copilot. **Ý nghĩa:** ACP mở rộng interoperability của coding agents, nhưng governance và billing vẫn phân mảnh giữa nền tảng.

**Nguồn chính thức:** https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air/

### 3. CodeQL 2.27.3 thêm AI threat model

**Ngày gốc: 03/11/2026.** CodeQL bổ sung threat model `ai` dạng opt-in cho dữ liệu do LLM tạo, hỗ trợ JSON data extensions và Python 3.15. **Quan trọng:** không có built-in AI sources; cần tự mô hình hóa sources bằng data extensions. GitHub Actions control-flow graph thay đổi có thể phá custom queries phụ thuộc CFG cũ. **Ý nghĩa:** có thể đưa LLM outputs vào taint analysis, nhưng phải cấu hình rõ nguồn và sinks; không thay thế runtime policy enforcement.

**Nguồn chính thức:** https://github.blog/changelog/2026-11-03-codeql-2-27-3-adds-python-3-15-features-and-json-data-extensions/

### 4. GitHub Desktop triển khai short-lived tokens

**Ngày gốc: 02/11/2026 — bổ sung muộn.** GitHub Desktop 3.6.10+ có thể dùng access tokens thời hạn ngắn, tự refresh khi đăng nhập mới. **Giới hạn:** rollout dần trên github.com/GHEC; sessions cũ không tự migrate, GHES chưa hỗ trợ. **Ý nghĩa:** giảm thời gian credential bị lạm dụng nếu rò rỉ, nhưng không thay thế scope restrictions và token revocation.

**Nguồn chính thức:** https://github.blog/changelog/2026-11-02-github-desktop-adds-short-lived-authentication-tokens/

### 5. GitHub security assessments thêm repository protection status

**Ngày gốc: 02/11/2026 — bổ sung muộn.** GitHub bổ sung trạng thái bảo vệ repository vào security risk assessments để hỗ trợ triage governance. **Giới hạn:** chỉ báo posture không chứng minh không có lỗ hổng. **Ý nghĩa:** hữu ích khi ưu tiên repositories cho coding/security agents dựa trên mức độ bảo vệ và bề mặt rủi ro.

**Nguồn chính thức:** https://github.blog/changelog/2026-11-02-security-risk-assessments-include-repository-protection-status/
