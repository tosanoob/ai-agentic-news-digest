## Breaking — Security / Frontier Models

### 1. GPT-6 Cyber: model an ninh mạng mức Critical, Daybreak Red giới hạn (05/11/2026; BACKFILL)
OpenAI giới thiệu GPT-6 Cyber dành cho nghiên cứu bảo mật được cấp phép. Trong benchmark ExploitGym của hãng, model đạt **48,5%**, so với **32,1%** của GPT-5.6 Cyber (tăng 16,4 điểm phần trăm; khoảng 51% tương đối). Trong đánh giá giới hạn phạm vi riêng, model không khai thác dịch vụ ngoài phạm vi ở 99,93% bài kiểm tra khi không có deployment prompt và 100% khi có prompt. OpenAI cho biết nghiên cứu sử dụng model tạo 948 exploit leo thang đặc quyền Linux và phát hiện 81 lỗ hổng Firefox nghiêm trọng chưa biết trước đó; nhiều bản vá Firefox đã phát hành. Mức phân loại **Critical** phản ánh năng lực an ninh mạng, không phải tuyên bố model an toàn tuyệt đối.

**Ý nghĩa kỹ thuật:** vulnerability triage có thể chuyển từ tìm kiếm CVE sang xác minh khả năng khai thác và hỗ trợ bản vá trong môi trường được phép. Cần xác thực scope, sandbox, audit tool calls và review độc lập. **Giới hạn:** benchmark và số liệu do OpenAI công bố, có sự khác biệt giữa môi trường benchmark và hệ thống thực; quyền truy cập ban đầu giới hạn cho đối tượng được duyệt, không phải API mở cho tất cả.

**Nguồn gốc:** https://openai.com/index/introducing-gpt-6-cyber/

## Enterprise Agents / GitHub Releases

### 2. Copilot impact dashboard thêm Chat và VS Code Agents (06/11/2026)
GitHub mở rộng biểu đồ adoption và báo cáo 28 ngày sang chín tính năng, thêm `chat` và `vscode_agent` trong `copilot_feature_engagement.totals_by_feature`. Nhóm “Passive users” đổi thành “Chat-first users”, nhưng không thay đổi các adoption phases. Engagement yêu cầu sử dụng tính năng ít nhất hai ngày trong 28 ngày; một người có thể nằm trong nhiều feature counts.

**Ý nghĩa:** có thể đánh giá mức sử dụng agent tốt hơn nhưng không suy diễn engagement thành năng suất hoặc ROI. **Giới hạn:** các báo cáo trước ngày thay đổi không có dữ liệu hai tính năng mới; Chat và VS Code Agents không tính vào adoption phases.

**Nguồn:** https://github.blog/changelog/2026-11-06-copilot-impact-dashboard-adds-chat-and-vs-code-agent-usage/

### 3. Copilot usage API hiển thị khoảng trống telemetry (05/11/2026; BACKFILL)
GitHub thêm `client_telemetry_present`, `usage_metrics_requirements`, `missing_client_telemetry_user_count` và `below_usage_metrics_minimum_user_count` trong báo cáo. Thiếu client telemetry có thể làm thiếu số liệu lines of code, features và models dù user vẫn được tính active.

**Ý nghĩa:** quản trị enterprise agents cần theo dõi coverage của measurement pipeline trước khi so sánh adoption/cost. **Giới hạn:** hai nhóm user có thể chồng lấp, không cộng hai counts; null không phải zero; dữ liệu trước ngày phát hành không backfill.

**Nguồn:** https://github.blog/changelog/2026-11-05-usage-metrics-api-flags-telemetry-and-version-gaps/

### 4. Copilot code review API bổ sung addressed rate (05/11/2026; BACKFILL)
Trong báo cáo repository-level `repos-1-day`, GitHub bổ sung `copilot_code_review` với `total_comments_evaluated`, `total_comments_addressed`, cùng phân loại severity, tier, comment type và customization. Addressed rate = addressed/evaluated.

**Ý nghĩa:** đo vòng phản hồi giữa coding agent và reviewer thay vì chỉ đếm comments. **Giới hạn:** addressed có thể là phản hồi hứa sửa trong PR sau, không chứng minh bug đã sửa hoặc review chính xác; số liệu là hoạt động chứ không phải controlled productivity benchmark.

**Nguồn:** https://github.blog/changelog/2026-11-05-usage-metrics-api-adds-code-review-details-and-addressed-rate/
