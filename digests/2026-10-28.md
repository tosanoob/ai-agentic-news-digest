### 1. Oracle and OpenAI expand enterprise partnership — 2026-10-27

### 2. IBM Agent Identity and HashiCorp Vault 2.2 — 2026-10-27
IBM introduced **Agent Identity** and **Vault 2.2**, GA, to give agents accountable identities and short-lived, scoped, revocable credentials. watsonx Orchestrate adds Discover and Contain in **tech preview**, plus evaluation and cost tracking; NVIDIA OpenShell integration links identity and sandbox enforcement.
**Implication:** combine identity, runtime policy and revocation; do not treat preview features as mature or proven in adversarial testing.
Source:
- https://newsroom.ibm.com/2026-10-27-ibm-introduces-identity-and-control-for-ai-agents,-securing-frontier-intelligence-for-the-enterprise

### 3. SAP TechEd 2026 Joule Work and Joule Studio — 2026-10-27
SAP announced existing **MCP/A2A** protocol integration, third-party invocation of Joule agents through a governed gateway, Enterprise AI Gateway for policy/routing/usage/audit, knowledge-graph grounding and new agent observability. Joule Studio early adopters can design n8n workflows; wider availability is planned.
**Implication:** interoperability and enterprise authorization are distinct concerns; an A2A/MCP connection does not itself authorize a transaction.
**Note:** this is a product adoption announcement, NOT a new MCP or A2A specification release.
Source:
- https://news.sap.com/2026/10/sap-teched-ai-developers-build-what-matters-autonomous-execution/

### 4. Akamai Inference and Agent Sandbox — 2026-10-27
Akamai introduced **Inference** (OpenAI-compatible managed APIs for open-weight/custom models) and **Agent Sandbox** (Spin/WebAssembly isolation separating agent runtime from agent-generated code). Limits cover compute, memory, outbound connections and system capabilities. **Both are beta.**
**Implication:** benchmark Wasm vs microVM vs container sandboxes for startup latency, syscalls, outbound access policy and cost before choosing a runtime.
Source:
- https://www.akamai.com/newsroom/press-release/akamai-launches-ai-inference-service-and-agent-execution-environment

## Research Papers — Oct 26 preprints, previously unreported

### 7. SkillLifeBench: Benchmarking Security Across the Lifecycle of Agent Skills
**Preprint, submitted 2026-10-26.** 388 paired scenarios, 14 models, 89 runtime tasks and 60 lifecycle tasks. Overall challenged lifecycle task completion **77.5%** vs joint task+security success **65.2%**; 103 runs completed the task *and* the attack objective. Execution provenance improved recovery joint success from **49.35% to 65.58%** in a matched setting.
**Implication:** verify the code actually executed, not merely the selected skill version; measure unauthorized side effects separately from task success.
**Caveat:** task suite and model-specific scores do not generalize to all agent deployments.
Source:
- https://arxiv.org/abs/2610.35215

### 8. Testing with Coding Agents: 114,134 merged PRs
**Preprint, submitted 2026-10-26.** Observational analysis of **114,134 PRs** across **391 Java repositories**; within-repository odds of agent-supported PRs changing tests were **1.65×** those of human-authored PRs after controlling for change size. Agents added tests more often, but quality and code-coverage results were mixed.
**Implication:** do not equate more generated tests with better coverage or maintainability; evaluate assertion strength and defect detection.
**Caveat:** observational study; association is not proof of causality.
Source:
- https://arxiv.org/abs/2610.35297
