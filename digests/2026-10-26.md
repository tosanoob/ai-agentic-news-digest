## Executive Summary

- **Google ADK (23 Oct GitHub release; notes dated 22 Oct):** Python 2.13.0 adds Jev-based TypesafeClassifier, ClassifierNode, MongoDB memory/session support, voice enhancements, eval improvements, and an OpenTelemetry GenAI v2 default.

## Breaking & Agent Security

### 1. OpenAI frontier training containment — 23 Oct 2026
OpenAI documented defense-in-depth protections: restricted containers, microVM isolation, outbound network and cloud perimeters, monitoring, an offline web environment, and high-compute agent red-teaming. The September 20 DNS incident and October 1 restart were earlier events; the detailed security report is new on October 23. Research containment is not identical to safeguards in customer products.  
**Why it matters:** production agent architectures should enforce tool and network permissions independently of model instructions.  
**Primary:** https://openai.com/index/securing-our-frontier-model-training-environment/  
**Reporting:** https://www.reuters.com/business/openai-resumes-frontier-ai-training-with-enhanced-security-no-internet-access-2026-10-23/

### 2. GitHub public monitoring improvements — 23 Oct 2026
GitHub public monitoring now supports secret-leak alert dismissal/reopening, audit trails, ongoing token validity checks for supported providers, REST querying and webhooks. Closing an alert does not revoke a leaked token. Currently public preview for eligible GitHub Enterprise Cloud.  
**Why it matters:** agent pipelines can automate detection and triage, but credential revocation remains a separate response step.  
**Primary:** https://github.blog/changelog/2026-10-23-public-monitoring-adds-triage-validity-api-and-webhooks/

## Agent Frameworks & Orchestration

### 3. Google ADK Python 2.13.0 — GitHub release 23 Oct UTC; notes 22 Oct
New `TypesafeClassifier` and `ClassifierNode` support classification-driven workflow routing using Jev; `LlmClassifier` offers a model-based alternative. Other features: MongoDB session/memory services (experimental), live audio barge-in, evaluation traces and timings, 12 stabilized experimental features. Release notes claim up to 8x faster turns in specific string-model-agent configurations; not an independent benchmark. **Breaking:** default OpenTelemetry GenAI semantic conventions v2 replace legacy `call_llm` spans.  
**Why it matters:** route bounded decisions with fast classifiers, reserve LLM planning for open-ended reasoning; review telemetry before upgrade.  
**Primary:** https://github.com/google/adk-python/releases/tag/v2.13.0

### 4. LangGraph Python maintenance releases — 23–24 Oct 2026
Grouped SDK 0.4.9 and CLI 0.4.38 (23 Oct) with core 1.2.17 (24 Oct): thread priority settings, `langgraph.json` priority configuration, recursion-limit handling and preservation of caller namespace in remote subgraph streams. These are incremental runtime changes, not a new model.  
**Why it matters:** reliability and queue priority matter for production long-running agents.  
**Sources:** https://github.com/langchain-ai/langgraph/releases/tag/sdk%3D%3D0.4.9 ; https://github.com/langchain-ai/langgraph/releases/tag/cli%3D%3D0.4.38 ; https://github.com/langchain-ai/langgraph/releases/tag/1.2.17

## Enterprise Agent Releases

### 5. Copilot usage metrics across clients — 23 Oct 2026
GitHub's new `totals_by_client` includes request counts, sessions, token usage and model selection modes for Copilot-backed clients including OpenCode, Claude Code and Codex. Distinct from the October 22 announcement about custom skills/MCP usage metrics. Counts reflect model calls, not user prompts; client labels are best-effort.  
**Why it matters:** enables more accurate cost and adoption measurement across coding agent interfaces.  
**Primary:** https://github.blog/changelog/2026-10-23-usage-metrics-api-adds-usage-from-tools-like-opencode/

### 6. GitHub Copilot and Teams consolidated app — 23 Oct 2026
A consolidated GitHub app in Teams connects issue notifications with Copilot cloud-agent investigation and PR creation. This is a packaging/integration update building on earlier Teams agent capabilities, not the first launch of Teams agent sessions. Legacy GitHub app retirement is scheduled for November 16.  
**Why it matters:** turns human discussion and issue alerts into reviewable agent actions.  
**Primary:** https://github.blog/changelog/2026-10-23-turn-notifications-into-code-with-github-copilot-in-teams/

### 7. Enterprise GitHub App installations GA — 23 Oct 2026
GitHub App enterprise installations reached general availability with expanded API coverage for governance, permissions, and security administration. GitHub recommends app credentials in place of classic PATs where supported.  
**Why it matters:** better scoped service identity and policy control for enterprise agent integrations.  
**Primary:** https://github.blog/changelog/2026-10-23-enterprise-installations-for-github-apps-generally-available/

## Papers & Benchmarks — Previously Unreported

### 8. AgentVQA — arXiv preprint submitted 22 Oct 2026
Benchmark of 1,000 agentic visual examples drawn from 23 datasets across web, robotics, egocentric video, games and spatial planning. Among 22 evaluated models, the best reaches **58.5% offline accuracy**. The authors identify visual-state grounding and tracking as primary weaknesses. **Caveat:** offline VQA accuracy is not end-to-end interactive agent task success; not confirmed peer-reviewed.  
**Paper:** https://arxiv.org/abs/2610.31494

### 9. PLE: Physical-Engineering's Last Exam — arXiv preprint submitted 21 Oct UTC
85 long-horizon engineering deliverables across electrical, civil, structural and mechanical domains; seven agent harnesses. Strongest configuration reportedly averages **50.6%**, **27 million tokens**, and **63 minutes per task**. **Caveat:** these are results in the authors' benchmark, not an independent estimate of professional replacement readiness; not confirmed peer-reviewed.  
**Paper:** https://arxiv.org/abs/2610.30537
