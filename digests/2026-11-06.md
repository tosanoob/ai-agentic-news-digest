## Security / GitHub Releases

### 1. GitHub Secret Scanning mở rộng detector và giảm false positives (05/11/2026)

GitHub bổ sung SpaceX vào chương trình secret scanning partner và detector `starlink_public_api_v2_secret`. Khi loại secret này xuất hiện trong public repository, GitHub có thể chuyển phát hiện cho nhà phát hành để thu hồi/rotate credential. GitHub cũng điều chỉnh bộ lọc false positives cho Alibaba, AWS, Google Cloud Storage, OpenVSX, Pydantic Logfire và Tencent, bao gồm yêu cầu cặp khóa phù hợp, giới hạn định dạng token và context matching chặt hơn.

**Ý nghĩa kỹ thuật:** Đối với coding agents có quyền tạo commit hoặc PR, secret scanning là một lớp bảo vệ bổ sung khi agent vô tình đưa credentials vào source. Những thay đổi về precision giúp giảm alert noise, nhưng không thay thế pre-commit controls, credential scoping hoặc rotation. Việc đối tác nhận báo cáo không đồng nghĩa mọi secret bị rò rỉ đã được thu hồi.

**Giới hạn bằng chứng:** Đây là cập nhật detector do GitHub công bố, không phải benchmark độc lập về precision/recall; không có chứng cứ về một cuộc tấn công mới. Phân biệt partner reporting cho public repositories với user secret alerts ở những repository đủ điều kiện.
