## Agent runtime & GitHub Releases

### 1. GitHub Actions hosted runners ngừng hỗ trợ ARM32 trên Linux/Windows — công bố 12/11/2026 (BACKFILL)

GitHub thông báo sẽ kết thúc hỗ trợ ARM32 job execution trên GitHub-hosted runners Linux và Windows vào 08/12/2026, bao gồm native AArch32 user-space execution. GitHub liên hệ quyết định này với việc ngừng hỗ trợ Node 20 và Node 24 không hỗ trợ ARM32.

**Ý nghĩa đối với AI coding agents:** Agent pipelines có thể phụ thuộc vào GitHub Actions để build/test ứng dụng nhúng, ARMv7 hoặc legacy toolchains. Một agent có thể tạo code hợp lệ nhưng các CI jobs ngừng hoạt động vì runtime thiếu kiến trúc, dẫn đến retry vô ích. Kiểm kê workflow matrices, native ARM32 tests và runner images; cân nhắc runner tự quản trị hoặc migration phù hợp. ARM64 không mặc nhiên tương đương ARM32.

**Evidence caveat:** Đây là kế hoạch ngừng hỗ trợ, chưa phải sự cố đã xảy ra. Chỉ nêu GitHub-hosted Linux/Windows; không suy rộng sang mọi self-hosted runners. Không có benchmark hoặc thống kê số workflows bị ảnh hưởng.
